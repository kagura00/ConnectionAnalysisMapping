# 操作方法

## 起動

解析後にローカルサーバーを起動する。

portable版のWindows:

```powershell
cd C:\path\to\connection-map-portable
launcher\connection-map.cmd serve
```

portable版のLinux/macOS:

```sh
cd /path/to/connection-map-portable
./launcher/connection-map.sh serve
```

local mode:

```powershell
cd C:\path\to\repository
uv run python .connection-map\analyzer\run.py serve `
  --input .connection-map\snapshots\analysis.json `
  --bundle .connection-map\snapshots\graph-bundle
```

Linux/macOSのlocal mode:

```sh
cd /path/to/repository
uv run python .connection-map/analyzer/run.py serve \
  --input .connection-map/snapshots/analysis.json \
  --bundle .connection-map/snapshots/graph-bundle
```

表示された`http://127.0.0.1:<port>/`をブラウザで開く。サーバーは既定で自分のPCからだけ接続できる。

local modeまたはportable版で引数を変える場合は[コマンドリファレンス](commands.md)を参照する。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | キャンバスを移動する |
| ホイール | 表示倍率を変更する |
| ノードをクリック | 関数・クラス・ファイルなどの詳細を表示する |
| ノードをダブルクリック | 対象周辺へ拡大し、詳細な接続を読み込む |
| 接続をクリック | 接続元、接続先、関係種別を表示する |
| `Esc` | 選択と詳細表示を解除する |

## 検索

左側の検索欄へ関数名、クラス名、ファイル名、識別子の一部を入力する。検索結果をクリックすると、対象の位置へ移動して詳細を表示する。

検索結果が多い場合は検索語を追加して絞り込む。大規模結果では検索結果を最大80件まで表示する。

## 表示言語

「表示言語」から対象を選択する。表示対象だけが切り替わり、解析はやり直さない。

複数言語の結果では、全言語または言語ごとの表示を選択できる。検索、目次、キャンバス表示が選択した言語に合わせて変わる。上部の総数は解析結果全体の値を示す。

## 詳細と接続の移動

右側の詳細欄では、次の情報を確認できる。

- 言語、種類、ファイル、ソース位置
- 戻り値の有無
- 実行形態（同期・非同期など）
- 識別子
- 接続の関係種別、元ノード、先ノード

接続の詳細にある「接続元へ移動」「接続先へ移動」を使うと、画面上の位置に関係なく接続をたどれる。集約された接続では「代表接続を表示」から個別の接続を読み込む。

## 解析診断

「解析診断」を開くと、構文回復、未解決参照、未対応構文などを確認できる。診断は解析結果の失敗だけを示すものではない。対象ファイルと位置を確認し、必要なら設定の除外範囲や使用言語を見直す。

## 目次と凡例

- 「目次」: ファイル・モジュール単位の一覧。クリックで移動する。
- 「凡例」: ノードの種類と接続の種類を確認する。

## レイアウト

「レイアウトを保存」で現在の座標・表示状態をJSONとして保存する。「レイアウトを読み込む」で保存済みJSONを戻す。解析結果とレイアウトは別管理なので、同じ解析スキーマとノード識別子を維持していれば、解析をやり直してもレイアウトを再利用できる。

## 大規模な結果

大規模結果では、初期画面に全ノード・全接続を描画しない。ズームと表示範囲に応じてチャンクを読み込み、接続を段階的に描画する。

画面に「未読込」や「接続描画中」と表示されても、解析結果が欠落したことを意味しない。表示範囲のチャンクは自動で追加取得する。選択したノードの詳細欄に追加読み込みが表示された場合は、そのボタンで関係を追加取得する。表示上限で省略された接続は、検索、ノード選択、接続詳細の移動から追跡する。ブラウザのチャンクキャッシュは12MiB・8チャンクを上限とし、上限を超えたデータは必要に応じて再取得する。

## 複数リポジトリ

portable版で複数リポジトリを解析すると、画面上部の「対象リポジトリ」から切り替えられる。切り替え時は前のリポジトリのグラフ、詳細状態、保存していないレイアウト変更を破棄し、選択したリポジトリの結果を読み込む。

解析対象のフォルダーを移動した場合、同じGitの`origin`が登録済みで一意なら既存の解析結果と設定を引き継ぐ。`origin`がない場合や同じ`origin`の登録が複数ある場合は自動判定せず、新しい登録として扱う。

## 終了

サーバーを起動したターミナルで`Ctrl+C`を押して終了する。ブラウザを閉じただけではサーバーは終了しない。
