# Third-party notices

This file is an inventory, not a legal opinion.

The Connection Analysis Mapping source package is distributed under the MIT
License in `LICENSE`. Its base Python package has no runtime dependencies.

Optional parser environments may install `tree-sitter-language-pack`,
`tree-sitter-vbnet`, or `sqlglot`. Those packages are not bundled in the base
source package or in the default portable runtime. Their license notices are
the responsibility of the environment that installs them.

Portable release archives that include a Python runtime contain a generated
`THIRD_PARTY_NOTICES.md` at the archive root. That file records the exact
provider, target, source archive URL, SHA-256, and license files copied from
the runtime used for that build.
